# Changelog

## 2.1.0 — 2026-08-01

- Reproduced all prespecified Gender–Science and Age IAT benchmarks.
- Added reconstruction and validation of the public standardized Age score.
- Added observed subgroup allocation analyses for birth sex, gender identity, approximate age band, and collection quarter.
- Added stratified-bootstrap pairwise comparisons of the sequence contrast with false-discovery-rate correction.
- Added age-band boundary sensitivity, finite-sample empirical resampling, and robustness analyses.
- Added publication figures, figure source data, execution documentation, and the final strengthening audit.
- Updated the software title and citation metadata for the revised methodological manuscript.

No raw data, participant-level data, or manuscript files are included in this release.

- Clarified that no participant-level subgroup allocation audit is included or reported as an empirical result.
